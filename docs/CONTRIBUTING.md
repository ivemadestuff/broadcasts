# Contributing

- Run `npm run lint` and `npm run format` before pushing; lint-staged also runs them on commit.
- Commit messages must follow [Conventional Commits](https://www.conventionalcommits.org) — commitlint enforces this via a git hook.
- The squash-merge title becomes the release commit, so keep it in [Conventional Commits](https://www.conventionalcommits.org) format.
